# GadgetCenter

Electronics storefront for new and refurbished laptops, desktops, printers, UPS, CCTV, and related products.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy `.env.example` to `.env.local` if you want to override contact details.

## GitHub Pages

The storefront is a static export at [https://yogipowar.github.io/gadget-center/](https://yogipowar.github.io/gadget-center/). Pushes to `main` deploy automatically.
